# catalog-service

Сервис управления меню. Хранит позиции каталога (роллы, суши, напитки). Каждая позиция привязана к конкретному магазину через `shop_id`.

**Порт:** `8082`  
Доступ через gateway: `/api/catalog/*`

## Роли

| Роль     | Права                        |
|----------|------------------------------|
| customer | Только чтение                |
| courier  | Только чтение                |
| shop     | Чтение и запись (только своё)|

## API

### Получить позиции каталога

`GET /api/catalog/items`

Параметры запроса:

| Параметр  | Тип | Описание                                    |
|-----------|-----|---------------------------------------------|
| `shop_id` | int | Фильтр по магазину (обязателен для customer)|

**Ответ `200`:**
```json
[
  {
    "id": 1,
    "shop_id": 3,
    "name": "Ролл Калифорния",
    "description": "Краб, авокадо, огурец",
    "price": 350,
    "type": "roll",
    "image_url": ""
  }
]
```

---

### Создать позицию

`POST /api/catalog/items` — только роль `shop`

**Тело запроса:**
```json
{
  "name": "Ролл Калифорния",
  "description": "Краб, авокадо, огурец",
  "price": 350,
  "type": "roll"
}
```

`shop_id` берётся из JWT автоматически (`X-User-ID` от gateway).

---

### Обновить позицию

`PUT /api/catalog/items/:id` — только владелец (shop)

---

### Удалить позицию

`DELETE /api/catalog/items/:id` — только владелец (shop)

## Переменные окружения

| Переменная  | Описание                        |
|-------------|---------------------------------|
| DB_HOST     | Хост PostgreSQL                 |
| DB_PORT     | Порт PostgreSQL (по умолч. 5432)|
| DB_DATABASE | Название БД                     |
| DB_USERNAME | Пользователь БД                 |
| DB_PASSWORD | Пароль БД                       |
| PORT        | Порт сервиса (по умолч. 8082)   |
