# catalog-service

Сервис управления меню. Хранит позиции каталога (роллы, сеты, напитки).

**Порт:** `8082`

> В разработке. Доступ через gateway: `/api/catalog/*`

## Роли

| Роль     | Права                        |
|----------|------------------------------|
| customer | Только чтение                |
| courier  | Только чтение                |
| shop     | Чтение и запись              |
