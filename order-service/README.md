# order-service

Сервис управления заказами. Создаёт заказы и отслеживает их статус в реальном времени через WebSocket.

**Порт:** `8083`

> В разработке. Доступ через gateway: `/api/orders/*`

## Статусы заказа

```
created → accepted → picked_up → delivered
```

Обновления приходят через WebSocket — клиент получает уведомление при каждом изменении статуса.
