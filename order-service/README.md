# order-service

Сервис управления заказами. Создаёт заказы, отслеживает статусы, поддерживает отказ курьера от заказа.

**Порт:** `8083`  
Доступ через gateway: `/api/orders/*`

## Статусы заказа

```
pending → accepted → picked_up → delivered
    └──────────────────────────► cancelled
```

- `pending` — создан покупателем, ждёт принятия магазином
- `accepted` — магазин принял, ждёт курьера
- `picked_up` — курьер забрал заказ
- `delivered` — доставлен
- `cancelled` — отменён магазином

## API

### Создать заказ

`POST /api/orders/` — только роль `customer`

**Тело запроса:**
```json
{
  "shop_id": 3,
  "address": "ул. Пушкина, д. 1",
  "items": [
    { "menu_item_id": 5, "quantity": 2 },
    { "menu_item_id": 12, "quantity": 1 }
  ]
}
```

---

### Список заказов

`GET /api/orders/` — все роли (каждая видит своё)

- `customer` — свои заказы
- `shop` — заказы своего магазина
- `courier` — заказы со статусом `accepted`

---

### Заказ по ID

`GET /api/orders/:id` — все роли

---

### Сменить статус

`PATCH /api/orders/:id/status` — все роли

```json
{ "status": "accepted" }
```

---

### Отказаться от заказа (курьер)

`POST /api/orders/:id/decline` — только роль `courier`

Курьер отказывается от заказа. Заказ возвращается в пул `accepted` и становится доступен другим курьерам. Повторный отказ от одного заказа запрещён.

## Переменные окружения

| Переменная          | Описание                         |
|---------------------|----------------------------------|
| DB_HOST             | Хост PostgreSQL                  |
| DB_PORT             | Порт PostgreSQL (по умолч. 5432) |
| DB_DATABASE         | Название БД                      |
| DB_USERNAME         | Пользователь БД                  |
| DB_PASSWORD         | Пароль БД                        |
| CATALOG_SERVICE_URL | Адрес catalog-service            |
| PORT                | Порт сервиса (по умолч. 8083)    |
